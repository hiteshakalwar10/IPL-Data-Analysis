# IPL Data Analysis

This project analyzes Indian Premier League (IPL) data from 2008–2023 using Python and Pandas.

The goal is to perform beginner-friendly cricket data analysis and practice core Pandas operations used in Data Analytics and Machine Learning.

## Project Objectives

Find the Top 10 Batsmen by Total Runs

Find the Best Economy Bowlers

Analyze Team Win Count

Analyze Team Wins Per Season

## Technologies Used

Python

Pandas

NumPy

Google Colab

## Dataset

Dataset used: IPL Dataset (2008–2023) from Kaggle.

Files used:

ipl_batting_card.csv

ipl_bowling_card.csv

ipl_historical.csv

ipl_players_info.csv

## Skills Demonstrated

Reading CSV files

Data Exploration

Data Cleaning

Data Merging (merge())

Grouping (groupby())

Aggregation (sum(), mean())

Sorting (sort_values())

Counting Values (value_counts())
